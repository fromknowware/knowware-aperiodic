# Knowware Aperiodic

A technology and engineering journal website inspired by IEEE Spectrum, serving as the publication platform for the A.R.C Institute of Knowware.

## Stack

- React 19 + TypeScript
- Vite 6
- Tailwind CSS v4
- Motion (Framer Motion)
- Lucide React

## Run Locally

**Prerequisites:** Node.js 18+

1. Install dependencies:
   ```
   npm install
   ```
2. Copy the environment template:
   ```
   cp .env.example .env.local
   ```
3. Start the dev server:
   ```
   npm run dev
   ```

The app runs at [http://localhost:3000](http://localhost:3000).

## Build

```
npm run build
npm run preview
```
